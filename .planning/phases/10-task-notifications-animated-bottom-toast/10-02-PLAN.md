  <files>Frontend/src/app/shared/services/task-toast.service.ts</files>
  <action>
1. Create `TaskToastService` (`providedIn: 'root'`):
   - Toast model interface `TaskToastItem`:
     `id: string`, `taskId: number`, `taskCode: string`, `subject: string`, `eventType: 'CREATED' | 'STATUS_CHANGED' | 'REASSIGNED' | 'RECURRENCE'`, `priority?: string`, `status?: string`, `actorName?: string`, `time: Date`.
   - RxJS `Subject<TaskToastItem>` and `Observable<TaskToastItem>` stream.
   - `show(item: Omit<TaskToastItem, 'id' | 'time'>): void`:
     - Assign unique ID and timestamp.
     - Emit on stream.
     - Call `playChime()`.
   - `playChime()` method:
     - Uses `window.AudioContext || (window as any).webkitAudioContext`.
     - Synthesizes a clean 2-tone harmonic chime: Tone 1 (523.25 Hz [C5]) followed 90ms later by Tone 2 (659.25 Hz [E5]) using sine wave oscillator and smooth exponential gain envelope decay (`gain.exponentialRampToValueAtTime(0.001, ...)`).
     - Handles browser autoplay audio context resume safely.
  </action>
  <verify>
    Verify unit build and instantiate service.
  </verify>
  <done>TaskToastService dispatches toast payloads and plays synthetic audio chime.</done>

1. Create `TaskToastNotificationComponent`:
   - Listens to `TaskToastService.toast$` stream.
   - Maintains active toasts stack (max 3 at once).
   - Auto-dismisses each toast after 5000ms timer; pauses timer on mouse hover (`mouseenter` / `mouseleave`).
   - Dispatches `onViewTicket(toast)` event.
2. Template (`task-toast-notification.component.html`):
   - Container fixed at bottom-center: `.task-toast-stack-bottom`.
   - Each toast card has:
     - Icon with subtle pulse animation (sparkle/check for created, refresh for status change).
     - Title with event description ("Task Created", "Status Changed to Done", etc.).
     - Subject preview and `#TaskCode` badge.
     - Action button: `<button class="btn-toast-view" (click)="viewTicket(t)"><i class="fa-solid fa-arrow-up-right-from-square"></i> View Ticket</button>`.
     - Close button `[X]`.
3. Styles (`task-toast-notification.component.scss`):
   - Glassmorphism dark/premium style with glowing border matching priority/status (`box-shadow: 0 10px 30px rgba(0,0,0,0.18), 0 0 15px rgba(59, 130, 246, 0.3)`).
   - Keyframe animations:
     ```scss
     @keyframes toastSlideUp {
       0% { transform: translateY(120%) scale(0.92); opacity: 0; }
       70% { transform: translateY(-4px) scale(1.02); opacity: 1; }

     }
     @keyframes toastFadeDown {
       0% { transform: translateY(0) scale(1); opacity: 1; }
       100% { transform: translateY(120%) scale(0.9); opacity: 0; }
     }
     ```
