<task type="auto" tdd="false">
  <name>Task 1: Stored Procedure for Stakeholder Notification Dispatch</name>
  <files>WebAPI/Scripts/HR_Task_Visibility_Phase08.sql</files>
  <action>
1. In `HR_Task_Visibility_Phase08.sql`, create `dbo.usp_HR_Task_DispatchNotification`:
   - Parameters:
     `@TaskId INT`,
     `@EventType VARCHAR(50)`, -- 'CREATED', 'STATUS_CHANGED', 'REASSIGNED', 'RECURRENCE_GENERATED'
     `@ActorEmpId VARCHAR(50) = NULL`,
     `@ActorName NVARCHAR(150) = NULL`,
     `@Remarks NVARCHAR(MAX) = NULL`
   - Logic:
     - Load task details from `dbo.HR_TaskMaster`: `TaskCode`, `Subject`, `Priority`, `TargetDeptId`, `AssignedToEmpId`, `CreatedByEmpId`, `CreatorDeptId`, `DueDate`.
     - Resolve recipient list (distinct `EmpId`):
       - Assignee (`AssignedToEmpId`)
       - Target Dept HOD (`hd.fk_depHodid` from `dbo.Department_Mst` where `pk_deptid = TargetDeptId`)
       - Reporting Manager of Assignee (`emp.Reporting_Manager_ID` or equivalent manager link from `SAL_Employee_Mst`)
       - Creator (`CreatedByEmpId`)
       - Exclude NULLs and empty IDs.
       - Deduplicate via `SELECT DISTINCT EmpId`.
     - Insert a master notification record into `dbo.LMS_Notification_Mst` (title, description, active = 1).
     - Insert mappings into `dbo.LMS_Notification_Employee_Map` for each recipient with `diffusion = 0, active = 1`.
2. Hook `dbo.usp_HR_Task_DispatchNotification` into:
   - `dbo.usp_HR_Task_Create`: call with `@EventType = 'CREATED'` after inserting master task.
   - `dbo.usp_HR_Task_UpdateStatusAndRemarks`: call with `@EventType = 'STATUS_CHANGED'` (or `'REASSIGNED'`) after updating status.
   - `dbo.usp_HR_Task_ProcessRecurring`: call with `@EventType = 'RECURRENCE_GENERATED'` for each generated child task.
3. Apply updated script to SQL Server database `HRBook`.
  </action>
  <verify>
    Execute a test task creation in SQL and verify recipient rows are inserted into `LMS_Notification_Employee_Map`.
  </verify>
  <done>All task events trigger stakeholder notifications saved in database notification tables.</done>
</task>
