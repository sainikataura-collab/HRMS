# Plan 03-02: Talent Bench Aadhaar Detection & Seamless Re-Allocation Integration

## Context
When candidates are archived or placed on the Talent Bench under older requisitions, recruiters and vendors often attempt to re-register them under new requisitions.
Currently, when `verifyAadhaarUniqueness` detects an existing candidate in the Talent Bench (`duplicateType === 'TALENT_BENCH'`), the response includes `existingRecord` details (candidate name, old MRF, previous role). However, the UI does not offer a direct one-click workflow to allocate that existing talent pool candidate to the active job requisition.

## Objectives
1. In `candidate-pipeline.component.ts` (Quick Add Candidate modal) and `vendor-add-candidate.component.ts`, recognize `duplicateType === 'TALENT_BENCH'` from `verifyAadhaarUniqueness`.
2. Display a dedicated informative alert: "Candidate [Name] with Aadhaar [X] is currently in the Talent Bench under MRF [Y]. Allocate to this requisition instead of creating a duplicate profile."
3. Provide a one-click "Allocate from Talent Bench" action that invokes `atsService.allocateBenchCandidateToJob()` (or equivalent allocation API) to re-engage the candidate without duplicating profile data.

## Tasks

### Task 1: Candidate Pipeline Talent Bench Prompt & Allocation
- In `Frontend/src/app/pages/all-dashboard/recruitment/candidate-pipeline/candidate-pipeline.component.ts`:
  - Enhance `quickAddForm` Aadhaar check to capture `benchRecord` when `duplicateType === 'TALENT_BENCH'`.
  - Add method `allocateBenchCandidate(candidateAppId: number, targetReqId: number)`.
- In `Frontend/src/app/pages/all-dashboard/recruitment/candidate-pipeline/candidate-pipeline.component.html`:
  - When `benchRecord` is present, display a distinctive blue/info banner with candidate name, previous MRF, and an "Allocate to this MRF" button.

### Task 2: Vendor Add Candidate Talent Bench Guidance
- In `Frontend/src/app/pages/all-dashboard/recruitment/vendor-add-candidate/vendor-add-candidate.component.ts` & `.html`:
  - When batch row Aadhaar returns `TALENT_BENCH`, set status to `'bench'` with badge "In Talent Bench".
  - Show informational helper text explaining that this candidate already exists in the talent pool and does not require re-registration.

## Verification Criteria
1. Typing the Aadhaar of a benched candidate displays the Talent Bench informative banner with previous MRF details.
2. Clicking "Allocate from Talent Bench" seamlessly connects the candidate to the active requisition.
3. No build commands (`dotnet build`, `ng build`) are executed; dev servers remain stable.
