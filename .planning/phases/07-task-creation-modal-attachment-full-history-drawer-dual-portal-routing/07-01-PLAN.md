# Plan 07-01: Task Creation Modal, Attachment & Full History Drawer & Dual Portal Routing

**Phase**: 07-task-creation-modal-attachment-full-history-drawer-dual-portal-routing  
**Plan**: 07-01-PLAN.md  
**Type**: Frontend Lifecycle Implementation  
**Estimated Effort**: 1 Wave  

---

## 1. Objectives & Context
Complete the task manager lifecycle by building:
1. `CreateTaskModalComponent`: Modal for creating one-off or recurring tasks with file attachments.
2. `TaskDetailDrawerComponent`: Slide-out/modal view for inspecting full details, attachments, chronological audit history timeline, and inline status updates.
3. Wire both into `TaskManagerComponent`.
4. Ensure sidebar navigation access in `DashboardSidebarComponent` or menu configuration.
5. Verify TypeScript compilation and complete end-to-end functionality.

---

## 2. Tasks Breakdown

### Task 1: Create CreateTaskModalComponent
- **Path**: `Frontend/src/app/pages/task-manager/components/create-task-modal/`
- **Files**:
  - `create-task-modal.component.ts`
  - `create-task-modal.component.html`
  - `create-task-modal.component.scss`
- **Features**:
  - Subject, Description, Department, Assignee (with self-assign shortcut), Priority, Deadline.
  - File upload with instant preview and upload to `/Uploads/Tasks`.
  - Recurrence controls: Toggle recurring, pattern (`DAILY`, `WEEKLY`, `MONTHLY`, `YEARLY`), interval, end date.
  - Emits `(taskCreated)` on successful creation.

### Task 2: Create TaskDetailDrawerComponent
- **Path**: `Frontend/src/app/pages/task-manager/components/task-detail-drawer/`
- **Files**:
  - `task-detail-drawer.component.ts`
  - `task-detail-drawer.component.html`
  - `task-detail-drawer.component.scss`
- **Features**:
  - Displays full task metadata, overdue warnings, recurrence details, and attachment preview/download.
  - Inline status update selector (`OPEN`, `CLOSED`, `ON HOLD`) with mandatory remarks on closing/holding.
  - Full audit history timeline showing chronological events (`CREATED`, `STATUS_CHANGE`, `RECURRENCE_GENERATED`), remarks, actor names, and time elapsed.
  - Emits `(statusChanged)` and `(closed)`.

### Task 3: Wire Components into TaskManagerComponent
- Update `TaskManagerComponent` to include `CreateTaskModalComponent` and `TaskDetailDrawerComponent`.
- Wire `(createTaskClicked)` to open create modal.
- Wire `(taskSelected)` to fetch task by ID and open detail drawer.
- Handle refresh triggers on task creation and drawer status updates.

### Task 4: Verify Navigation & Sidebars
- Check `DashboardSidebarComponent` or menu items to ensure Task Manager is accessible.
- Verify TypeScript compilation and build.

---

## 3. Verification Criteria
- Task creation succeeds with both standard and recurring options.
- Attachments upload to `/Uploads/Tasks` and link in task details.
- Task details drawer fetches full chronological history.
- `npx tsc --noEmit` verifies zero TypeScript errors.
