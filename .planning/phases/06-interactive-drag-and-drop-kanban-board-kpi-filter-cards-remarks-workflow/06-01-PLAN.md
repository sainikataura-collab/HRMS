# Plan 06-01: Interactive Drag-and-Drop Kanban Board, Top KPI Filter Cards & Remarks Workflow

**Phase**: 06-interactive-drag-and-drop-kanban-board-kpi-filter-cards-remarks-workflow  
**Plan**: 06-01-PLAN.md  
**Type**: Frontend Implementation  
**Estimated Effort**: 1 Wave  

---

## 1. Objectives & Context
Deliver the interactive, real-time Kanban board frontend module for HRBook:
1. `TaskManagerService` connecting Angular to `/api/v1/TaskManager/*` endpoints.
2. Top clickable KPI summary cards with live counters and active toggle filter states.
3. Multi-filter toolbar (`28px` height, `.custom-ng-select`, search input, Reset and Refresh actions).
4. 3-Column Angular CDK Drag-and-Drop Kanban Board (`OPEN`, `CLOSED`, `ON HOLD`) strictly matching the visual design, typography, pills, and chips in the reference image.
5. Mandatory Status Transition Remarks Modal displayed on cross-column card drag-and-drop with rollback if canceled.
6. Route registration in both HR Dashboard and Employee Task-Box.

---

## 2. Tasks Breakdown

### Task 1: Create TaskManagerService and TypeScript Interfaces
- **File**: `Frontend/src/app/shared/services/task-manager.service.ts`
- **Interfaces**:
  - `TaskCardDto`: `taskId`, `taskCode`, `subject`, `description`, `departmentId`, `departmentName`, `assignedToEmpId`, `assignedToEmpName`, `createdByName`, `createdByEmpId`, `priority`, `status`, `deadlineDate`, `isOverdue`, `overdueHours`, `relativeAgeText`, `isRecurring`, `hasAttachments`, `createdAt`.
  - `TaskSummaryCountDto`: `allTasks`, `openTasks`, `closedTasks`, `onHoldTasks`, `unassignedTasks`, `overdueTasks`.
  - `TaskBoardResponseDto`: `counts: TaskSummaryCountDto`, `openTasks: TaskCardDto[]`, `closedTasks: TaskCardDto[]`, `onHoldTasks: TaskCardDto[]`.
  - `TaskBoardFilterDto`: `viewerEmpId`, `scope`, `departmentId`, `assignedToEmpId`, `createdByEmpId`, `priority`, `recurrencePattern`, `searchKeyword`, `filterCard`.
  - `TaskStatusUpdateRequestDto`: `taskId`, `newStatus`, `remarks`, `updatedByEmpId`, `updatedByName`.
  - `TaskLookupsDto`: `departments: { id: string, name: string }[]`, `employees: { id: string, name: string, departmentId: string, departmentName: string, isHod: boolean }[]`.
- **Methods**:
  - `getBoard(filter: TaskBoardFilterDto): Observable<TaskBoardResponseDto>`
  - `getLookups(): Observable<TaskLookupsDto>`
  - `updateStatusAndRemarks(request: TaskStatusUpdateRequestDto): Observable<any>`
  - `getTaskById(taskId: number): Observable<any>`
  - `uploadAttachment(formData: FormData): Observable<any>`
  - `createTask(payload: any): Observable<any>`

### Task 2: Create Transition Remarks Modal Component
- **Path**: `Frontend/src/app/pages/task-manager/components/transition-remarks-modal/`
- **Files**:
  - `transition-remarks-modal.component.ts`
  - `transition-remarks-modal.component.html`
  - `transition-remarks-modal.component.scss`
- **Features**:
  - Modal overlay / Bootstrap 5 modal styling conforming to `.planning/codebase/DESIGN.md`.
  - Displays task code, task subject, from status badge, to status badge.
  - Textarea for remarks with validation (required if moving to Closed or On Hold, or default required).
  - "Confirm Move" and "Cancel" buttons.
  - Emits `(confirmed)="onRemarksConfirmed($event)"` and `(cancelled)="onRemarksCancelled()"`.

### Task 3: Create Main TaskManagerComponent
- **Path**: `Frontend/src/app/pages/task-manager/`
- **Files**:
  - `task-manager.component.ts`
  - `task-manager.component.html`
  - `task-manager.component.scss`
- **Features**:
  - Top KPI Summary Cards:
    - 6 Bento cards: All, Open, Closed, On Hold, Unassigned, Overdue.
    - Active border/accent when selected, 1-click filter toggle.
  - Multi-Filter Toolbar:
    - Scope toggle / select: All Viewable, My Assigned Tasks, My Department Tasks, Tasks Created by Me.
    - Department select (`.custom-ng-select`, `28px`).
    - Assignee select (`.custom-ng-select`, `28px`).
    - Priority select (`.custom-ng-select`, `28px`).
    - Search input (`.form-control.form-control-sm`, `28px`).
    - "+ Create Task" button (emits event / triggers modal in Phase 7).
    - "Reset" button & "Refresh" button.
  - 3-Column CDK Drag-and-Drop Board:
    - Columns: `● OPEN` (blue), `● CLOSED` (gray), `● ON HOLD` (amber).
    - Count pill in each column header (`46`, `37`, `1`).
    - Card items matching user screenshot:
      - Header: Task code (e.g. `CJD_CRM-2026-1083`), Overdue tag (`⚠️ Overdue by 15.3h`), Priority border pill (`MEDIUM`, `HIGH`).
      - Subject: Bold 12.5px dark text.
      - Department & relative age (`🏢 FLIPKART INDIA...`, `2 day(s) ago`).
      - Footer: Purple pill `● BY: [Name]`, Blue pill `● TO: [Name]` or `● TO: Unassigned`.
    - CDK drag placeholder and preview styling.
    - Drag drop handler with pending transition interception and remarks modal invocation.
