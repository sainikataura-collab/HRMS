Create idempotent script (`CREATE OR ALTER`), stored procedures/functions only:

1. `dbo.fn_HR_Task_ResolveViewer(@ViewerId VARCHAR(50), @UserType VARCHAR(20))` — inline TVF returning ONE row:
   `EmpId, UserId, RoleId, CompanyId, DeptId, IsAdmin`. **Branch strictly on @UserType — never guess by ID existence (IDs collide).**
   - `@UserType = 'Employee'` → EmpId = @ViewerId (must exist in `SAL_Employee_Mst`); UserId/RoleId from `UM_Users_Mst WHERE fk_empId = EmpId AND active = 1` (D-07).
   - `@UserType = 'User'` → UserId = @ViewerId (must exist in `UM_Users_Mst`); EmpId = `fk_empId`; RoleId = `fk_roleId`.
   - Any other / NULL @UserType → zero rows.
   All task SPs gain `@UserType VARCHAR(20) = NULL` and pass it through; `fn_HR_Task_VisibleTasks(@ViewerId, @UserType, @CompanyId)`.
   - `IsAdmin = CASE WHEN RoleId IN (1,2) THEN 1 ELSE 0 END` (D-03).
   - No match → returns zero rows (D-05).

2. `dbo.fn_HR_Task_VisibleTasks(@ViewerId VARCHAR(50), @CompanyId VARCHAR(50))` — inline TVF returning
   `TaskId, VisibilityReason` (DISTINCT TaskId) for `HR_TaskMaster t WHERE t.IsActive = 1 AND t.CompanyId = ISNULL(@CompanyId, v.CompanyId)` where viewer row exists and ANY of:
   - `v.IsAdmin = 1`                                                          → 'ADMIN'
   - `t.CreatedByEmpId = v.EmpId OR t.CreatedByUserId = v.UserId`             → 'CREATOR'
   - `t.AssignedToEmpId = v.EmpId`                                            → 'ASSIGNEE'
   - `t.AssignedToEmpId IN (emps WHERE fk_FunctionalRepempid = v.EmpId OR fk_AdministrativeRepempid = v.EmpId)` → 'MANAGER' (D-01)
   - HOD depts H = `Department_Mst WHERE fk_depHodid = v.EmpId`:
       `t.TargetDeptId IN H` (incl. unassigned pool, D-04)                   → 'HOD_TARGET'
       `t.CreatorDeptId IN H`                                                → 'HOD_CREATOR_DEPT'
       `t.AssignedToEmpId IN (emps WHERE fk_deptid IN H)`                    → 'HOD_ASSIGNEE_DEPT' (D-02)
   Use `COLLATE DATABASE_DEFAULT` on all VARCHAR comparisons (existing pattern). Use EXISTS, not joins, to avoid row multiplication.

3. `ALTER dbo.usp_HR_Task_GetBoard`: keep signature + both result sets byte-compatible (KPI row first, tasks second).
   - Delete lines building #HodDepts/#TeamMembers, the role-scoping block, and the admin fallback (old lines 58–95, 155–165).
   - `INNER JOIN dbo.fn_HR_Task_VisibleTasks(@ViewerId, @CompanyId) vis ON vis.TaskId = t.TaskId`.
   - Scope chip rewrite (still additive filter on top of visibility):
     `MY_TASKS` → assignee = v.EmpId; `CREATED_BY_ME` → creator match; `SELF_TASKS` unchanged;
     `DEPT_TASKS` → `vis.VisibilityReason LIKE 'HOD_%'` OR (v.IsAdmin = 1 AND t.TargetDeptId IS NOT NULL) (D-08).
     Note: reason column must be deterministic per task — compute reason priority in the TVF with a CASE (ADMIN > CREATOR > ASSIGNEE > HOD_* > MANAGER) BUT DEPT_TASKS must use a separate `IsDeptVisible` bit column (1 when any HOD_* predicate is true) — add that column to the TVF instead of matching the reason string.
   - Keep `EXEC usp_HR_Task_ProcessRecurring @SuppressOutput = 1;` at top.
