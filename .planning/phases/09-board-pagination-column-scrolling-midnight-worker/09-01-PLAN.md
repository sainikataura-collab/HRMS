  <name>Task 2: Stored Procedure & Backend Models for Column-Level Pagination</name>
  <files>WebAPI/Scripts/HR_Task_Visibility_Phase08.sql, WebAPI/Models/TaskManagerModels.cs, WebAPI/Controllers/TaskManagerController.cs, WebAPI/Repository/ITaskManagerRepository.cs, WebAPI/Repository/TaskManagerRepository.cs</files>
  <action>
1. In `dbo.usp_HR_Task_GetBoard`:
   - Add parameters:
     `@TargetStatus VARCHAR(20) = NULL`,
     `@PageIndex INT = 1`,
     `@PageSize INT = 10`
   - When `@TargetStatus IS NULL` (initial full board load):
     - Result Set 1 returns full aggregate KPI counts (`COUNT(*)`, `OpenTasks`, `ClosedTasks`, etc.).
     - Result Set 2 uses `ROW_NUMBER() OVER (PARTITION BY Status ORDER BY CASE Priority WHEN 'URGENT' THEN 1 WHEN 'HIGH' THEN 2 WHEN 'MEDIUM' THEN 3 WHEN 'LOW' THEN 4 ELSE 5 END, DueDate ASC, CreatedAt DESC) AS RowNum` and filters `WHERE RowNum <= @PageSize` (default 10).
     - Result Set 3 returns `ViewerContext`.
   - When `@TargetStatus IS NOT NULL` (column infinite scroll load for 'OPEN', 'CLOSED', or 'ON_HOLD'):
     - Returns Result Set 1 (Cards for that status matching filters, sorted by Priority/DueDate, using `OFFSET (@PageIndex - 1) * @PageSize ROWS FETCH NEXT @PageSize ROWS ONLY`).
2. In `TaskManagerModels.cs`:
   - Add `TargetStatus`, `PageIndex`, `PageSize` to `TaskBoardFilterDto` and `BoardRequestPayload`.
   - Add `HasMore` indicators to `TaskBoardResponseDto`.
3. In `TaskManagerRepository.cs` and `ITaskManagerRepository.cs`:
   - Support `GetBoardAsync` and add `GetColumnTasksAsync(TaskBoardFilterDto filter)` to fetch additional pages per column.
4. In `TaskManagerController.cs`:
   - Expose `GET/POST /api/TaskManager/board/column` or pass parameters through `board` endpoint.
5. Apply updated stored procedure to database `HRBook`.
  </action>
  <verify>
    Execute `sqlcmd` test verifying initial board returns top 10 per status and column query with `@TargetStatus = 'OPEN', @PageIndex = 2, @PageSize = 10` returns next 10 tasks.
  </verify>
  <done>Database and backend API serve paginated tasks per column while keeping KPI counts accurate.</done>
