1. Create `WebAPI/Repository/ITaskManagerRepository.cs` in namespace `HRMSWebAPI.Repository` declaring:
   - `Task<TaskLookupsResponseDto> GetLookupsAsync(string? viewerId, string? userType, int? roleId);`
   - `Task<TaskBoardResponseDto> GetBoardAsync(TaskBoardFilterDto filter);`
   - `Task<TaskDetailResponseDto?> GetTaskByIdWithHistoryAsync(int taskId);`
   - `Task<(int TaskId, string TaskCode)> CreateTaskAsync(CreateTaskRequestDto dto, string? attachmentName, string? attachmentPath);`
   - `Task<bool> UpdateStatusAndRemarksAsync(TaskStatusTransitionRequestDto dto, string? attachmentName, string? attachmentPath);`
   - `Task<int> ProcessRecurringTasksAsync();`

2. Create `WebAPI/Repository/TaskManagerRepository.cs` in namespace `HRMSWebAPI.Repository` using `DataBaseFactory.ConnString()` and Dapper (`CommandType.StoredProcedure`) per D-03, D-04, D-05, D-06, D-07, D-08:
   - `GetLookupsAsync`: Calls `dbo.usp_HR_Task_GetLookups` via `QueryMultipleAsync`, reading `TaskViewerRoleDto` (Result Set 1), `TaskDepartmentLookupDto` list (Result Set 2), and `TaskEmployeeLookupDto` list (Result Set 3).
   - `GetBoardAsync`: Calls `dbo.usp_HR_Task_GetBoard` via `QueryMultipleAsync`, reading `TaskKpiSummaryDto` (Result Set 1) and `List<TaskCardDto>` (Result Set 2). Partitions the returned tasks into `OpenTasks` (`Status == "OPEN"`), `ClosedTasks` (`Status == "CLOSED"`), and `OnHoldTasks` (`Status == "ON_HOLD"`), and populates `AllTasks`.
   - `GetTaskByIdWithHistoryAsync`: Calls `dbo.usp_HR_Task_GetByIdWithHistory` via `QueryMultipleAsync`, reading `TaskCardDto` (Result Set 1) and `List<TaskHistoryItemDto>` (Result Set 2).
   - `CreateTaskAsync`: Calls `dbo.usp_HR_Task_Create` and returns `(TaskId, TaskCode)`.
   - `UpdateStatusAndRemarksAsync`: Calls `dbo.usp_HR_Task_UpdateStatusAndRemarks` and returns `true` when updated.
   - `ProcessRecurringTasksAsync`: Calls `dbo.usp_HR_Task_ProcessRecurring` and returns the count of generated recurring task instances.

3. Create `WebAPI/Services/RecurringTaskHostedService.cs` in namespace `HRMSWebAPI.Services` inheriting `BackgroundService` (per D-08, API-02):
   - Injects `IServiceScopeFactory` and `ILogger<RecurringTaskHostedService>`.
   - On startup (after a 5-second delay) and every 15 minutes in a `PeriodicTimer` loop, creates a scope, resolves `ITaskManagerRepository`, and invokes `ProcessRecurringTasksAsync()`, catching and logging any transient DB exceptions so the host never crashes.

   - Helper method `ResolveViewerId(string? explicitId)`: Returns `explicitId` if non-empty, else `HttpContext.Items["DecryptedUserId"]?.ToString()`.
   - Helper method `SaveAttachmentAsync(IFormFile? file)` (per D-09):
     - If `file == null || file.Length == 0`, returns `(null, null)`.
     - Ensures directory `Path.Combine(Directory.GetCurrentDirectory(), "Uploads", "Tasks")` exists.
     - Sanitizes original filename, prepends `Guid.NewGuid().ToString("N")[..8] + "_"`, saves to disk, and returns `(file.FileName, $"/Uploads/Tasks/{storedFileName}")`.
   - `GET /api/v1/TaskManager/lookups`: Accepts `[FromQuery] string? viewerId`, `[FromQuery] string? userType`, `[FromQuery] int? roleId`. Returns `Ok(new { isSuccess = true, data = lookups })`.
   - `GET /api/v1/TaskManager/board`: Accepts `[FromQuery] TaskBoardFilterDto filter`. Resolves `filter.ViewerId = ResolveViewerId(filter.ViewerId)`. Calls `_repository.GetBoardAsync(filter)` and returns `Ok(new { isSuccess = true, data = board })`.
   - `GET /api/v1/TaskManager/{taskId:int}`: Calls `_repository.GetTaskByIdWithHistoryAsync(taskId)` and returns `Ok(new { isSuccess = true, data = detail })` (or `NotFound` if null).
   - `POST /api/v1/TaskManager/create`: Accepts `[FromForm] CreateTaskRequestDto dto` (supporting `multipart/form-data` with optional `Attachment` file) and also create `[HttpPost("create-json")]` accepting `[FromBody] CreateTaskRequestDto dto` for pure JSON callers. Validates `Subject` is not empty and `DueDate` is valid. Saves attachment if provided, resolves `ActionById = ResolveViewerId(dto.ActionById)`, calls `_repository.CreateTaskAsync`, and returns `Ok(new { isSuccess = true, message = "Task created successfully.", taskId, taskCode })`.
   - `POST /api/v1/TaskManager/transition`: Accepts `[FromForm] TaskStatusTransitionRequestDto dto` and `[HttpPost("transition-json")]` accepting `[FromBody] TaskStatusTransitionRequestDto dto`. Validates `TaskId > 0`, `NewStatus` in `("OPEN", "CLOSED", "ON_HOLD")`, and `Remarks` is non-empty (returns `400 BadRequest` if `Remarks` is blank). Saves optional attachment, resolves `ActionById = ResolveViewerId(dto.ActionById)`, calls `_repository.UpdateStatusAndRemarksAsync`, and returns `Ok(new { isSuccess = true, message = "Task updated successfully." })`.
   - `POST /api/v1/TaskManager/process-recurring`: Calls `_repository.ProcessRecurringTasksAsync()` and returns `Ok(new { isSuccess = true, generatedCount })`.
