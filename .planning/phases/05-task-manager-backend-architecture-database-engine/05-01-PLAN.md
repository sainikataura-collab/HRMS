Create idempotent SQL setup script `WebAPI/Scripts/HR_TaskManager_Setup.sql` and execute it against the local SQL Server `HRBook` database (`Server=localhost;Database=HRBook;User Id=sa;Password=123456;TrustServerCertificate=True`).

1. **Table `dbo.HR_TaskMaster` (per D-01, D-06, D-08, D-09, DB-01)**:
   - `TaskId INT IDENTITY(1,1) PRIMARY KEY`
   - `TaskCode VARCHAR(50) NOT NULL UNIQUE` (e.g. `HR_TSK-2026-1001`)
   - `Subject NVARCHAR(250) NOT NULL`
   - `Description NVARCHAR(MAX) NULL`
   - `Priority VARCHAR(20) NOT NULL DEFAULT 'MEDIUM'` (`HIGH`, `MEDIUM`, `LOW`)
   - `Status VARCHAR(20) NOT NULL DEFAULT 'OPEN'` (`OPEN`, `CLOSED`, `ON_HOLD`)
   - `TargetDeptId VARCHAR(50) NULL` (links to `Department_Mst.pk_deptid`)
   - `AssignedToEmpId VARCHAR(50) NULL` (links to `SAL_Employee_Mst.pk_empid`; NULL when Unassigned per D-06)
   - `CreatedByEmpId VARCHAR(50) NULL` (links to `SAL_Employee_Mst.pk_empid`)
   - `CreatedByUserId VARCHAR(50) NULL` (links to `UM_Users_Mst.pk_userId`)
   - `CreatedByName NVARCHAR(150) NULL`
   - `CreatorDeptId VARCHAR(50) NULL`
   - `DueDate DATETIME NOT NULL`
   - `AttachmentName NVARCHAR(255) NULL` (per D-09)
   - `AttachmentPath NVARCHAR(500) NULL` (per D-09)
   - `IsRecurring BIT NOT NULL DEFAULT 0` (per D-08)
   - `RecurrenceType VARCHAR(20) NULL DEFAULT 'NONE'` (`NONE`, `DAILY`, `WEEKLY`, `MONTHLY`, `YEARLY` per D-08)
   - `RecurrenceInterval INT NOT NULL DEFAULT 1`
   - `NextOccurrenceDate DATETIME NULL`
   - `ParentTaskId INT NULL`
   - `IsSelfTask BIT NOT NULL DEFAULT 0`
   - `ClosedAt DATETIME NULL`
   - `CompanyId VARCHAR(50) NULL`
   - `CreatedAt DATETIME NOT NULL DEFAULT GETDATE()`
   - `UpdatedAt DATETIME NOT NULL DEFAULT GETDATE()`
   - `IsActive BIT NOT NULL DEFAULT 1`
   - Create non-clustered indexes on `(Status, IsActive)`, `(AssignedToEmpId)`, `(CreatedByEmpId)`, `(TargetDeptId)`, and `(IsRecurring, NextOccurrenceDate)`.

2. **Table `dbo.HR_TaskHistory` (per D-02, DB-02)**:

   - `TaskId INT NOT NULL REFERENCES dbo.HR_TaskMaster(TaskId)`
   - `ActionType VARCHAR(50) NOT NULL` (`CREATED`, `STATUS_CHANGED`, `ASSIGNED`, `REMARK_ADDED`, `EDITED`, `ATTACHMENT_ADDED`, `RECURRENCE_GENERATED`)
   - `OldStatus VARCHAR(20) NULL`
   - `NewStatus VARCHAR(20) NULL`
   - `OldAssigneeEmpId VARCHAR(50) NULL`

   - `AttachmentName NVARCHAR(255) NULL`
   - `AttachmentPath NVARCHAR(500) NULL`
   - `ActionByEmpId VARCHAR(50) NULL`
   - `ActionByUserId VARCHAR(50) NULL`
   - `ActionByName NVARCHAR(150) NULL`
   - `CreatedAt DATETIME NOT NULL DEFAULT GETDATE()`
   - Create index on `(TaskId, CreatedAt DESC)`.

3. **Stored Procedures (per D-03, D-04, D-05, D-06, D-07, D-08, DB-03)**:
   - `dbo.usp_HR_Task_GetLookups (@ViewerId VARCHAR(50) = NULL, @UserType VARCHAR(20) = NULL, @RoleId INT = NULL)`:
     - Resolves the viewer's identity: if `@ViewerId` matches `UM_Users_Mst.pk_userId`, extracts `fk_empId`, `fk_roleId`, `name`; if `@ViewerId` matches `SAL_Employee_Mst.pk_empid`, extracts employee details (`pk_empid`, `empname`, `fk_deptid`, `isHod`).
     - Resolves HOD status per D-04: checks if viewer's `EmpId` is in `Department_Mst.fk_depHodid` OR `SAL_Employee_Mst.isHod = '1'` OR referenced by any active employee's `fk_FunctionalHODempid` or `fk_AdministrativeHODempid`.
     - Resolves Manager status per D-04: checks if viewer's `EmpId` is referenced by any active employee's `fk_rmanagerid`, `fk_imanagerid`, `fk_FunctionalRepempid`, or `fk_AdministrativeRepempid`.
     - Result Set 1: Viewer Role & Context (`ViewerEmpId`, `ViewerUserId`, `ViewerName`, `ViewerDeptId`, `ViewerDeptName`, `IsAdmin`, `IsHod`, `IsManager`).
     - Result Set 2: Active Departments (`pk_deptid AS DeptId`, `description AS DeptName`, `fk_depHodid AS HodEmpId`) from `Department_Mst WHERE ISNULL(dep_active, 1) = 1 ORDER BY description`.
     - Result Set 3: Active Employees (`e.pk_empid AS EmpId`, `e.empcode AS EmpCode`, `e.empname AS EmpName`, `e.fk_deptid AS DeptId`, `ISNULL(d.description, '') AS DeptName`, `e.email AS Email`) from `SAL_Employee_Mst e LEFT JOIN Department_Mst d ON e.fk_deptid = d.pk_deptid WHERE e.active = 1 AND ISNULL(e.employeeleftstatus, 'N') = 'N' ORDER BY e.empname`.
   - `dbo.usp_HR_Task_GetBoard`:
     - Parameters: `@ViewerId VARCHAR(50) = NULL`, `@UserType VARCHAR(20) = NULL`, `@RoleId INT = NULL`, `@Scope VARCHAR(30) = 'ALL'`, `@DeptId VARCHAR(50) = NULL`, `@AssignedToEmpId VARCHAR(50) = NULL`, `@CreatedByEmpId VARCHAR(50) = NULL`, `@Status VARCHAR(20) = NULL`, `@Priority VARCHAR(20) = NULL`, `@RecurrenceType VARCHAR(20) = NULL`, `@OnlyUnassigned BIT = 0`, `@OnlyOverdue BIT = 0`, `@SearchText NVARCHAR(200) = NULL`.
     - Automatically invokes `EXEC dbo.usp_HR_Task_ProcessRecurring` first so due recurring tasks are always up to date when the board loads.
     - Resolves `@ViewerEmpId`, `@ViewerUserId`, `@IsAdmin`, `@IsHod`, `@IsManager` using the exact D-04/D-05 rules:
       - `@IsAdmin = 1` when `@RoleId IN (1, 2, 7)` OR `UM_Users_Mst.fk_roleId IN (1, 2, 7)` OR (`@UserType = 'User'` AND `@ViewerEmpId IS NULL`).
       - Base visibility set (`#AccessibleTasks` temp table):
         - If `@IsAdmin = 1`: all active tasks (`t.IsActive = 1`).
         - Otherwise tasks where:
           - `t.CreatedByEmpId = @ViewerEmpId` OR `t.CreatedByUserId = @ViewerUserId` (Creator always sees per D-05)
           - OR `t.AssignedToEmpId = @ViewerEmpId` (Assignee sees per D-05)
           - OR `t.TargetDeptId IN (SELECT DeptId FROM #HodDepts)` OR `t.CreatorDeptId IN (SELECT DeptId FROM #HodDepts)` (HOD of target or creator department sees per D-05)
           - OR `t.AssignedToEmpId IN (SELECT EmpId FROM #TeamMembers)` OR `t.CreatedByEmpId IN (SELECT EmpId FROM #TeamMembers)` (HOD/Manager sees subordinate tasks per D-05).
     - Computes Result Set 1 (KPI Summary Counts on `#AccessibleTasks` before status/unassigned quick-card filter, or respecting non-status dropdown filters so clicking KPI cards toggles seamlessly per D-07): `TotalCount`, `OpenCount`, `ClosedCount`, `OnHoldCount`, `UnassignedCount`, `OverdueCount`, `MyAssignedCount`, `DeptTaskCount`, `CreatedByMeCount`, `SelfTaskCount`.
     - Applies `@Scope` (`ALL`, `MY_TASKS`, `DEPT_TASKS`, `CREATED_BY_ME`, `SELF_TASKS`), `@DeptId`, `@AssignedToEmpId`, `@CreatedByEmpId`, `@Status`, `@Priority`, `@RecurrenceType`, `@OnlyUnassigned`, `@OnlyOverdue`, and `@SearchText` filters.
     - Result Set 2: Filtered task list ordered by `CASE WHEN t.Status <> 'CLOSED' AND t.DueDate < GETDATE() THEN 0 ELSE 1 END`, `CASE t.Priority WHEN 'HIGH' THEN 1 WHEN 'MEDIUM' THEN 2 ELSE 3 END`, `t.CreatedAt DESC`, returning all columns plus `DepartmentName`, `CreatedByDisplayName`, `AssignedToDisplayName` (`ISNULL(empAssign.empname, 'Unassigned')`), `AssignedToEmpCode`, `IsOverdue` (`CASE WHEN t.Status <> 'CLOSED' AND t.DueDate < GETDATE() THEN CAST(1 AS BIT) ELSE CAST(0 AS BIT) END`), `OverdueHours` (`CASE WHEN t.Status <> 'CLOSED' AND t.DueDate < GETDATE() THEN CAST(ROUND(DATEDIFF(MINUTE, t.DueDate, GETDATE()) / 60.0, 1) AS DECIMAL(10,1)) ELSE 0 END`), `AgeMinutes` (`DATEDIFF(MINUTE, t.CreatedAt, GETDATE())`), and `HistoryCount`.
   - `dbo.usp_HR_Task_Create`:
     - Parameters: `@Subject NVARCHAR(250)`, `@Description NVARCHAR(MAX) = NULL`, `@Priority VARCHAR(20) = 'MEDIUM'`, `@Status VARCHAR(20) = 'OPEN'`, `@TargetDeptId VARCHAR(50) = NULL`, `@AssignedToEmpId VARCHAR(50) = NULL`, `@DueDate DATETIME`, `@AttachmentName NVARCHAR(255) = NULL`, `@AttachmentPath NVARCHAR(500) = NULL`, `@IsRecurring BIT = 0`, `@RecurrenceType VARCHAR(20) = 'NONE'`, `@RecurrenceInterval INT = 1`, `@IsSelfTask BIT = 0`, `@ActionById VARCHAR(50) = NULL`, `@ActionByName NVARCHAR(150) = NULL`, `@CompanyId VARCHAR(50) = NULL`, `@InitialRemarks NVARCHAR(MAX) = NULL`.
     - Resolves `@CreatedByEmpId`, `@CreatedByUserId`, `@CreatorDeptId`, and `@ResolvedActorName` from `@ActionById`.
     - If `@TargetDeptId IS NULL AND @AssignedToEmpId IS NOT NULL`, defaults `@TargetDeptId` to the assignee's `fk_deptid`.
     - Generates sequential `@TaskCode = 'HR_TSK-' + CAST(YEAR(GETDATE()) AS VARCHAR(4)) + '-' + RIGHT('0000' + CAST((ISNULL((SELECT MAX(TaskId) FROM dbo.HR_TaskMaster), 1000) + 1) AS VARCHAR(10)), 4)`.
     - Computes `@NextOccurrenceDate` if `@IsRecurring = 1` and `@RecurrenceType IN ('DAILY','WEEKLY','MONTHLY','YEARLY')` using `DATEADD`.
     - Inserts into `dbo.HR_TaskMaster` and inserts initial `CREATED` record into `dbo.HR_TaskHistory` (and if `@AttachmentName IS NOT NULL`, records attachment info).
     - Returns the newly created `TaskId` and `TaskCode`.
   - `dbo.usp_HR_Task_UpdateStatusAndRemarks`:
     - Parameters: `@TaskId INT`, `@NewStatus VARCHAR(20)`, `@Remarks NVARCHAR(MAX)`, `@NewAssigneeEmpId VARCHAR(50) = '__KEEP__'`, `@NewPriority VARCHAR(20) = NULL`, `@NewDueDate DATETIME = NULL`, `@AttachmentName NVARCHAR(255) = NULL`, `@AttachmentPath NVARCHAR(500) = NULL`, `@ActionById VARCHAR(50) = NULL`, `@ActionByName NVARCHAR(150) = NULL`.
     - Validates `@Remarks` is not null/empty.
     - Updates `dbo.HR_TaskMaster` in a transaction (`Status`, `ClosedAt` when `CLOSED`, optional `AssignedToEmpId`, `Priority`, `DueDate`, `AttachmentName`, `AttachmentPath`, `UpdatedAt = GETDATE()`).
     - Inserts audit record into `dbo.HR_TaskHistory` with `ActionType` (`STATUS_CHANGED` if status changed, `ASSIGNED` if assignee changed, or `REMARK_ADDED` / `EDITED`), `OldStatus`, `NewStatus`, `OldAssigneeEmpId`, `NewAssigneeEmpId`, `Remarks`, `AttachmentName`, `AttachmentPath`, `ActionByEmpId`, `ActionByUserId`, `ActionByName`.
     - Returns `Success = 1`, `TaskId`, `NewStatus`.
   - `dbo.usp_HR_Task_GetByIdWithHistory (@TaskId INT)`:
     - Result Set 1: Full single task row with joined `DepartmentName`, `CreatorDeptName`, `CreatedByDisplayName`, `AssignedToDisplayName`, `OverdueHours`, `IsOverdue`, `ParentTaskCode`.
     - Result Set 2: Chronological `dbo.HR_TaskHistory` rows (`ORDER BY CreatedAt DESC, HistoryId DESC`) with joined `OldAssigneeName`, `NewAssigneeName`, `ActionByDisplayName`.
   - `dbo.usp_HR_Task_ProcessRecurring`:
     - Finds all active recurring tasks (`IsActive = 1 AND IsRecurring = 1 AND RecurrenceType IN ('DAILY','WEEKLY','MONTHLY','YEARLY') AND NextOccurrenceDate IS NOT NULL AND NextOccurrenceDate <= GETDATE()`).
     - Cursor/set loop spawns a new child task instance in `dbo.HR_TaskMaster` with `Status = 'OPEN'`, `ParentTaskId = TaskId`, updated `DueDate`, `IsRecurring = 0` on the spawned child (template task remains the recurring generator), inserts `RECURRENCE_GENERATED` into `dbo.HR_TaskHistory` on both child and parent, and advances `NextOccurrenceDate` on the template task until `NextOccurrenceDate > GETDATE()`.
  </action>
