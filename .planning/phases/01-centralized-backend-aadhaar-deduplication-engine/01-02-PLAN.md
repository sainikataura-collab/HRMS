# Plan 01-02: WebAPI Models, Repository Methods, and Controller Validation Endpoints

## Purpose
Expose a unified, high-performance REST endpoint in `AtsLifecycleController.cs` and connect it via `AtsLifecycleRepository.cs` to `usp_REC_ValidateAadhaarCard`. Update `AtsJobRequisitionController.cs` to leverage this shared deduplication logic.

## Proposed Changes

### 1. `WebAPI/Models/AtsLifecycleModels.cs`
- Add `ValidateAadhaarRequestDto`:
  ```csharp
  public class ValidateAadhaarRequestDto
  {
      public string AadhaarNo { get; set; } = string.Empty;
      public string? CompanyId { get; set; }
      public long? CurrentAppId { get; set; }
  }
  ```
- Add `ValidateAadhaarResultDto`:
  ```csharp
  public class ValidateAadhaarResultDto
  {
      public bool IsSuccess { get; set; }
      public bool IsDuplicate { get; set; }
      public bool CanProceed { get; set; }
      public string DuplicateType { get; set; } = "NONE"; // NONE, EMPLOYEE, ACTIVE_PIPELINE, TALENT_BENCH, BLACKLISTED
      public string Message { get; set; } = string.Empty;
      public string? ExistingName { get; set; }
      public string? ExistingIdentifier { get; set; } // EmpCode or ApplicationNo
      public string? ExistingStage { get; set; }
      public string? ExistingMrf { get; set; }
      public string? ExistingVendor { get; set; }
      public long? ExistingAppId { get; set; }
  }
  ```

### 2. `WebAPI/Repository/IAtsLifecycleRepository.cs` & `AtsLifecycleRepository.cs`
- Add interface method:
  ```csharp
  Task<ValidateAadhaarResultDto> ValidateAadhaarUniquenessAsync(string aadhaarNo, string? companyId, long? currentAppId);
  ```
- Implement `ValidateAadhaarUniquenessAsync` calling `dbo.usp_REC_ValidateAadhaarCard` via Dapper.

### 3. `WebAPI/Controllers/RecruitmentManagementController/AtsLifecycleController.cs`
- Add endpoint:
  ```csharp
  [HttpPost("VerifyAadhaarUniqueness")]
  [AllowAnonymous] // Allows public walk-in link as well as authenticated vendor/HR portal
  public async Task<IActionResult> VerifyAadhaarUniqueness([FromBody] ValidateAadhaarRequestDto dto)
  ```
- Handle validation, company scoping, and error handling.

### 4. `WebAPI/Controllers/RecruitmentManagementController/AtsJobRequisitionController.cs`
- Update existing `CheckCandidateAadhaar` action to call `_lifecycleRepository.ValidateAadhaarUniquenessAsync` to guarantee identical duplicate evaluation logic across endpoints.

## Verification Plan
- Build `WebAPI` using `dotnet build` ensuring 0 compilation errors and 0 warnings.
- Test endpoint via PowerShell HTTP POST call against `http://localhost:7142/api/v1/AtsLifecycle/VerifyAadhaarUniqueness` with sample test payloads.
